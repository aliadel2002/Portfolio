SHEET 01 — DIGITAL DESIGN

32-bit MIPS CPU

Verified against the full MIPS instruction set with Tcl-driven simulation and C/C++ testbenches; assembly test programs and waveform analysis confirmed correct multiplication and branching.

SHEET 02 — EMBEDDED SYSTEMS

Elevator Simulation System

Microcontroller-based elevator simulation written in ARM Cortex-M assembly. Stepper motors and a 7-segment display represent car position and floor, with UART communication into Tera Term for live monitoring of state and movement.

Tools STM32 · ARM Cortex-M Assembly · Stepper Motors · UART / Tera Term
SHEET 03 — IMAGE PROCESSING

Sheet Music Processor

Image-processing application that detects and classifies musical notes from scanned sheet music and renders them as playable audio. Custom algorithms identify pitch, duration, and staff position, built with OpenCV as part of a 4-person team.

Tools Python · OpenCV
SHEET 04 — ALGORITHMS

Sliding Tile Puzzle Solver

A* search implementation for the classic 8-tile sliding puzzle, built on a custom min-heap frontier and hash-based explored set. Tuned for minimal path cost across the state-space search, verified through extensive testing.

Tools C++ · A* Search Algorithm
SHEET 05 — PCB / FIRMWARE

BOP IT! Multiplayer Game

Custom PCB integrating an ATMEGA328p, counter ICs, 7-segment displays, and dual IMU sensors capturing accelerometer and gyroscope data for a motion-controlled multiplayer game. Game logic issues audible commands, validates sensor input in real time, tracks the fastest accurate player, and progressively shortens the response window.

Tools ATMEGA328p · Custom PCB Design · Dual IMU Sensors · Counter ICs
SHEET 06 — CYBERSECURITY

Offline Dictionary Attack on a Password Authentication System

ECE 1155 Information Security lab simulating a stolen password database and running an offline dictionary attack against it — first with unsalted MD5, then with salted bcrypt. Compares crack rate against wordlist size and attack time against hash algorithm to demonstrate, empirically, why salted slow hashes defeat this class of attack.

Tools Python · bcrypt · Jupyter Notebook
